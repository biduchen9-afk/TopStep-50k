## Acceptance
Per trial: dev Sharpe (ATR-normalised daily R, 2010-2022; walk-forward out-of-sample for ML) -> deflated Sharpe ratio (Bailey-Lopez de Prado) for N = 144 trials using the cross-trial variance of Sharpes, skew and kurtosis of the trial's own daily returns.
Accepted only if ALL hold: deflated Sharpe probability >= 0.95; positive Sharpe in >= 60% of dev calendar years; hold-out (2023+) Sharpe > 0; stationary-block-bootstrap p-value < 0.05 on dev; every trade inside 09:30-15:55 ET. Accepted ideas are then checked with a Monte Carlo reshuffle through the Topstep rule state machine (pass and breach probability).
If something is accepted on one market, the same configuration is run on the other two markets as confirmation (not counted as new trials). Overlays (#48-58) are tested afterwards only on the existing NQ basket (not as trials): daily-loss breaker, consistency cap, trade-count limiter, buffer lock; reported as the change in dev farm value.
Weaker readings: "weak evidence" if the deflated probability is 0.8-0.95. Everything is reported, accepted or not.
